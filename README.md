# lembergtrans.com — staging preview

Прототип нового корпоративного сайту **Lemberg Group** (lembergtrans.com) для узгодження
з клієнтом і передачі розробнику. Це **не бойовий сайт**.

## Що тут

| Шлях | Що це |
|---|---|
| `/` | робочий прототип, 10 сторінок — для перегляду й правок |
| `/figma/` | збірка під імпорт у Figma через плагін **html.to.design** (іконки та ефекти переведені в реальні вузли) |

У квадратних дужках `[...]` — дані, які ще має надати клієнт. Вигаданих цифр тут немає.

## Індексація вимкнена

Кожна сторінка обох збірок містить:

```html
<meta name="robots" content="noindex, nofollow">
```

`robots.txt` у корені репозиторію теж є, але для GitHub Pages **project page**
(`/lembergtrans-preview/`) він не діє — пошуковики читають robots.txt лише з кореня домену
`olehvitkalg.github.io`. Тому індексацію тримає саме мета-тег, і його не можна прибирати,
поки сайт живе на цій адресі.
